# Security Policy

## Supported versions

Until `1.0.0`, security fixes are applied to the latest published version.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at risk.

Use GitHub's private vulnerability reporting for this repository when available. If that channel is unavailable, contact the LB FRAME maintainers privately before publishing technical details.

Include:

- affected version or commit
- impact
- reproduction steps or proof of concept
- suggested mitigation, if known

We will validate the report, coordinate a fix when necessary, and credit reporters who want attribution.
