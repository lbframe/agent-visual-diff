# Mask benchmark

Measures what `--mask` does to the three sites that motivated the feature, on real captures.

```bash
npm run bench
```

## Method

For each site, three comparisons of the same pair:

1. **baseline** — no mask.
2. **masked** — the site's mask file, covering the known-dynamic zones only.
3. **masked + injected bug** — a synthetic defect painted *outside* every mask zone, to prove
   masking does not swallow real differences.

Plus one repeat of the masked run to confirm byte-identical JSON.

The bug is generated by [`inject-bug.mjs`](inject-bug.mjs) (a solid fill over a rectangle), so
the run is reproducible from committed inputs.

## Fixtures

Captures come from the clone repos' `docs/design-references/` folders, outside this repository:

| Site | Pair | Viewport |
| --- | --- | --- |
| Duna | `duna-com-7c5a0f0d/root-8a5edab2/desktop-full.png` vs `desktop-full-hydrated.png` | 1440x9610 |
| Stripe | `stripe-com-9ababc9a/root-8a5edab2/reco-desktop.png` vs `reco-clone-typed.png` | 1440x900 |
| Apple | `apple-com-736d3707/spacing-review-2026-09-25/reference-desktop-gallery-1440x1000.png` vs `clone-desktop-gallery-1440x1000.png` | 1440x1000 |

Every path is overridable: `AVD_BENCH_DUNA_A`, `AVD_BENCH_DUNA_B`, `AVD_BENCH_STRIPE_A`,
`AVD_BENCH_STRIPE_B`, `AVD_BENCH_APPLE_A`, `AVD_BENCH_APPLE_B`, `AVD_BENCH_OUT`.

Comparisons use the same settings as the original QA reviews: `includeAA true`,
`mergeGap 10`, `regionPadding 2`, `minRegionPixels 20` (10 for Apple).

## Masks

Derived from evidence, not guesses. Duna's `root-8a5edab2/section-*-t*.png` sets are four
captures of the *same* section 3 seconds apart; comparing frame 1 to frame 4 shows 4–10% drift
in the same coordinates every time, which is what identified the count-up, the accordion and
the card stacks as dynamic.

| Site | Masked zones |
| --- | --- |
| Duna | `stats-countup`, `testimonial-carousel`, `product-accordion-autocycle`, `news-card-carousel` |
| Stripe | `hero-canvas-animation`, `live-transaction-feed`, `recommender-typing-animation` |
| Apple | `gallery-carousel-strip`, `gallery-thumb-left`, `gallery-side-right` |

The injected bug sits in the hero / middle of the viewport on each site, outside all masks.

## Reading the numbers

**Duna** — 90.7% of the reported difference was dynamic. The masked run leaves 0.66% over
8.6M evaluated pixels, and every surviving region sits outside the mask: the news card
*captions* below the masked images are static text, and a real change there still surfaces.

**Apple** — 96.5% removed. The gallery carousel, its side thumbnails and the active pill are
one component; masking it leaves the headline and navigation under test.

**Stripe** — only 29% removed, and the masked *percentage* goes **up** (15.36% → 17.44%).
Both are correct, and the second one is the point. After the animated canvas, the live
transaction feed and the typing animation are excluded, what remains is one 1295x153 heading
offset — 93.5% of the surviving diff, a real clone defect. Because the denominator shrank from
1,296,000 to 810,000 pixels, the same 141,267 changed pixels now represent a larger share.
A mask must not be tuned to lower a number; here it isolates the finding.

## Files

scenarios, including the gray excluded-zone overlay.
